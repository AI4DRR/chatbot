Datum

A conversational AI assistant for disaster-loss data exploration and analysis.

About Datum

Datum is an LLM-powered conversational data assistant to interrogate disaster-loss data, generate visualisations and provide source citations.

It provides faster and more accessible analysis of disaster-loss data, allowing users to obtain grounded answers, charts and supporting evidence without manually constructing database queries.
